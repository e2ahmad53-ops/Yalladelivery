# تجربة مجانية على Render

هذه تجربة ببيانات وهمية فقط، وليست نظام تشغيل تجاري. إعداد الملفات لا يعني أن الخدمة نُشرت.

## النشر من التلفون

1. افتح https://dashboard.render.com وسجل الدخول أو أنشئ حسابك.
2. اربط GitHub مع Render واسمح له بالوصول إلى مستودع e2ahmad53-ops/Yalladelivery فقط.
3. اختر New ثم Blueprint وحدد المستودع والفرع render-free-demo؛ ملف render.yaml يحدد خدمة واحدة بخطة Free.
4. في YALLA_DEMO_PASSWORD أدخل كلمة مرور خاصة بالتجربة من 16 إلى 200 حرف دون مسافات طرفية. لا ترسل كلمة المرور في المحادثة ولا تضعها على GitHub.
5. تحقق من أن الخطة Free قبل النشر. لا توافق على ترقية مدفوعة.
6. بعد وصول الخدمة إلى Live افتح عنوان HTTPS الذي يعطيك Render. تحقق أيضاً من /api/health.

إذا لم تظهر Blueprint، استخدم New > Web Service وحدد المستودع مع الإعدادات التالية:
- Runtime: Python 3
- Branch: render-free-demo
- Root Directory: اتركه فارغاً
- Build Command: python -m compileall -q backend
- Start Command: python backend/demo_server.py
- Instance Type: Free
- Health Check Path: /api/health
- Environment: PYTHON_VERSION=3.12.8، YALLA_DEMO=1، YALLA_DB=/tmp/yalla-demo/yalla.sqlite3، وكلمة المرور الخاصة في YALLA_DEMO_PASSWORD.

## الحسابات

كل الحسابات تستعمل كلمة مرور التجربة التي أدخلتها في Render:
- الإدارة: demo-admin
- المتجر: demo-store
- الكابتن الأول: demo-captain-1
- الكابتن الثاني: demo-captain-2

افتح لوحة الإدارة بحساب الإدارة. حسابات المتجر والكابتن لتطبيقات الهاتف أو اختبار API؛ لوحة الإدارة ليست واجهة متجر أو كابتن.
رصيد الكابتن الافتتاحي 10 دنانير وهمية. لا تستخدم بيانات أو أموالاً حقيقية.

## حدود التجربة

Render Free يوقف الخدمة بعد 15 دقيقة من عدم الاستخدام، وقد تستغرق العودة نحو دقيقة.
قاعدة SQLite هنا محلية مؤقتة: قد تُفقد الطلبات والحسابات والتعديلات عند النوم أو إعادة التشغيل أو النشر.
عند فقد الملف، يعيد مدخل التجربة إنشاء الحسابات الوهمية. لا نحذف ملفاً موجوداً عند تشغيل المدخل مجدداً.
تغيير متغير كلمة المرور لا يغير كلمات حسابات موجودة في الملف؛ يلزم قاعدة تجربة جديدة لتطبيقه.
لا يتطلب هذا الإعداد Render Postgres ولا ينشئ قاعدة مجانية ذات انتهاء 30 يوماً.
HTTPS توفره الاستضافة؛ الخادم المرفق مخصص للتجربة خلف بوابتها، ولم يُجهّز للتشغيل التجاري.

بعد نجاح الخدمة نضبط EXPO_PUBLIC_API_URL على عنوانها ثم نبني APK منفصلاً للمتجر والكابتن.
لم يُنتج هذا الإعداد APK أو إشعارات خلفية أو ميزات إضافية.
