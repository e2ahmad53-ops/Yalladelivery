# حالة النسخة 0.1.0

هذه نسخة جديدة من الصفر بسبب عدم توفر ملفات النسخة السابقة. لا نفترض صحة ادعاء سابق بوجود كود أو نجاح 11 فحصاً.

| المجال | الحالة والحدود |
|---|---|
| الطلبات والتوزيع | API وتنفيذ أول قبول، منع السباق، انتقال حالات، وتقييد المنطقة |
| طلبان أو ثلاثة | حتى 3 مع مجموعة طريق يدوية؛ لا تحسين جغرافي أو مسارات محسوبة |
| تحويل طلب بين كباتن | قبل استلام البضاعة؛ النقل أثناء وجودها مع كابتن يحتاج إجراء تسليم عهدة |
| المحفظة | أرصدة داخلية بالفلس الأردني ومعاملات ذرية وسجل تحويلات وعمولات؛ لا بوابة مالية |
| شات الدعم والطلبات | نصي مع تحديث دوري؛ لا مرفقات، لا سجل قراءة ولا إشعارات push |
| التتبع | مشاركة موقع أمامية، عرض آخر تحديث؛ لا تتبع عند إغلاق التطبيق ولا خدمات خلفية |
| خرائط الإدارة | خريطة خارجية لكل كابتن؛ لا خريطة موحدة بأسطول كامل أو تخطيط طرق |
| جدولة الطلب | وقت Unix، عرض عند الاستحقاق في التحديث الدوري؛ لا تذكير push |
| طلب صوتي | غير منفّذ؛ يلزم تسجيل وصلاحية ميكروفون وتخزين وربط بالطلب |
| التطبيقات | مصدر مشترك ودوران وملفات بناء منفصلة؛ لم تُبنَ APK/IPA أو تُختبر هواتف فعلية |
| الهوية | اسم يلا دليفري وألوان أولية؛ الشعار الرسمي لم يُضمّن كأصل رسومي |
| صلاحيات الإدارة | دور ومنطقة؛ يحتاج أدواراً فرعية مثل دعم فقط/مالية فقط وآلية تعطيل الحساب |
| المصادقة | كلمة مرور مشفرة PBKDF2 وجلسة 24 ساعة وإلغاء جلسة؛ لا OTP أو استعادة كلمة مرور |
| الإشعارات | تحديث داخل الشاشة؛ لا تسليم إشعار إذا التطبيق مغلق |

## سلوك الرصيد

كل مبلغ في API عدد صحيح بالفلس، 1000 فلس = دينار واحد. سعر توصيل 2000 فلس يحجز عمولة 300 فلس. التسليم يخصم 300 فلس من الرصيد ويحرر الحجز. سعر التوصيل نفسه لا يضاف إلى محفظة الكابتن آلياً؛ التحصيل من المتجر/الزبون والتسويات النقدية خارج نطاق هذه النسخة.

التحويل لا يستخدم الرصيد المحجوز. لكل عملية مفتاح `idempotency_key` يجب استخدامه نفسه عند إعادة المحاولة بعد فقد الاتصال. تطبيق الكابتن يحفظ التحويل غير المؤكد في SecureStore لإعادة المحاولة دون خصم جديد. لا توجد رسوم تحويل في هذه النسخة.

عند تحويل الطلب، يُحرر حجز الكابتن القديم ويُحجز على الجديد داخل نفس المعاملة. يحتاج الكابتن الجديد رصيداً متاحاً وتوفراً في منطقة الطلب ومجموعة طريق مناسبة؛ فشل النقل لا يغير الإسناد القديم.

## نشر لاحق

1. تحديد استضافة HTTPS وقاعدة بيانات ونسخ احتياطي، ومنع كشف قاعدة البيانات أو كلمات المرور.
2. بناء التطبيقيْن واختبار الدخول والطلبات والمحفظة والموقع على أندرويد وآيفون فعلياً.
3. إشعارات push وتحديثات الخلفية وفق قيود أنظمة الهواتف وموافقة الموقع.
4. حساب مسارات وتجميع طلبات بناءً على عنوان/إحداثيات فعلية.
5. صلاحيات موظفين مفصلة، استعادة دخول، تغيير كلمة مرور، تعطيل الحساب، وسجل إدارة مرئي.
6. إجراءات مالية ومصالحة وسحب/تسويات، واعتمادها قبل أي أرصدة حقيقية.
7. الطلب الصوتي، الشعار الرسمي، وتجربة جدول الوقت المحلي بدلاً من إدخال ISO النصي.

الخادم المبني على مكتبة Python `http.server` للتطوير. ليس خادم نشر تجاري، ولا يملك حماية موزعة من المحاولات أو مراقبة تشغيل أو خطة تعافٍ. العملات والتسويات تحتاج اعتماد صاحب الشركة قبل التشغيل الحقيقي.
