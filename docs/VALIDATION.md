# سجل التحقق — 2026-10-09

## نتائج منفّذة فعلياً

- `python3 -m unittest discover -s backend/tests -v`: نجحت 17 حالة، تشمل التزامن في قبول الطلب والتحويل، منع تجاوز الرصيد، حماية المحجوز، إعادة المحاولة بنفس مفتاح التحويل، نقل حجز العمولة، فشل النقل دون تغيير الإسناد، العمولة مرة واحدة، صلاحيات المنطقة والمحادثات، إغلاق التتبع، وطلبات HTTP فعلية لخادم محلي.
- `node --check apps/admin/admin.js`: نجح فحص صياغة JavaScript.
- `npm run typecheck`: نجح TypeScript strict للكود المحمول.
- تثبيت الحزم نجح، مع حفظ `package-lock.json` لتثبيت نفس النسخة.
- فحص توافق Expo المحلي بعد تحديث الحزم أعاد `Dependencies are up to date`. تم استخدام وضع offline؛ تحقق التوافق البعيد لم يكتمل بسبب مهلة proxy.
- `EXPO_OFFLINE=1 npx expo export --platform android --platform ios --output-dir dist`: نجح Metro/Hermes لكلا المنصتين لنسخة المتجر الافتراضية.
- `EXPO_PUBLIC_APP_ROLE=captain EXPO_OFFLINE=1 npx expo export --platform android --platform ios --output-dir dist/captain`: نجح التجميع لكلا المنصتين لنسخة الكابتن أيضاً.

## حدود التحقق

لا يوجد اختبار على جهاز أندرويد أو آيفون، ولا APK/IPA ولا رفع إلى متاجر التطبيقات. التجميع لا يختبر إذن الموقع أو قيود الشبكة أو الشهادات أو خدمات الخلفية. لا توجد معاينة بصرية فعلية للواجهة؛ متصفح Chromium لم يتوفر وتعذر تنزيله في البيئة. فحص لوحة الإدارة هو صياغة JavaScript وHTTP، ولا يمثل تحققاً بصرياً أو اختبار نقرات شامل.

لا توجد خدمات استضافة أو مفاتيح إنتاج أو كلمات مرور حقيقية في الملفات المرفوعة. فحوصات الاختبار تستخدم قاعدة مؤقتة وحسابات اصطناعية. الخادم التجريبي يحتاج إعداد نشر مستقلاً، ولا يعد رفع GitHub نشر خدمة عاملة.
